## PROFILE - CAELESTIA KDE

This repo hosts [caelestia-kde/README.md](profile/README.md)

The readme theme is from [metawka/expressive-profile](https://github.com/metawka/expressive-profile)

It is automatically updated by [expressive-profile.yml](.github/workflows/expressive-profile.yml) which has been modified to support GitHub organisations.

To update README layout, [profile.json](profile.json) has to be updated.

Either edit it manually or head to [expressive-profile](https://metawka.github.io/expressive-profile/) and Download updated layout as Zip. Then push `profile.json` and the workflow should take care of rest.
